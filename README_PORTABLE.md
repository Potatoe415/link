# MagnetFinder - Portable Version

This is a standalone web application to find magnet links.

## Installation on a new machine

1. Ensure **Node.js** is installed on the machine.
2. Copy this entire folder to the machine.
3. Open a terminal in this folder and run:
   ```bash
   npm install --production
   ```

## Launching

Simply run the launcher for your operating system:
- **Windows:** Double-click `launch-windows.bat`
- **macOS:** Double-click `launch-mac.command`

The application will be available at **http://localhost:3000**.
