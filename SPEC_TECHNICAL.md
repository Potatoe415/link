# MagnetFinder - Technical Specifications

## 1. Tech Stack
- **Frontend:** React 19 (TypeScript), Vite, Tailwind CSS, Lucide Icons.
- **Backend:** Node.js (Express), Axios (HTTP), Cheerio (HTML Parsing), He (HTML Entities Decoding).
- **Deployment:** Vercel (Serverless Functions) or Local Node.js server.

## 2. Architecture

### 2.1. Dual-Runtime Strategy
The project is designed to run in two modes:
1.  **Local Mode:** Uses `start.js` as a standard Express server (Port 3000). Bypass Cloud-blocks by using the user's home IP.
2.  **Cloud Mode (Vercel):** Uses `api/search.js` as a Serverless Function.

### 2.2. Folder Structure
- `/api`: Vercel serverless logic.
- `/api/engines`: Modular JSON configurations for each search engine.
- `/src`: React frontend source code.
- `/dist`: Production build (generated by `npm run build`).
- `/public`: Static assets.

## 3. Search Engine Modular System
Engines are defined in `/api/engines/*.json`. This allows adding or fixing a source without changing the core logic.

### 3.1. Config Schema
- `id`: Unique identifier.
- `type`: `api` or `scraper`.
- `urls`: `primary` and `mirrors` (with `{{q}}` placeholder).
- `selectors`: CSS selectors for `rows`, `title`, `magnet`, `size`, `seeders`, `date`.

### 3.2. Mirror Rotation
For Pirate Bay (Apibay), the system implements an automatic fallback:
- Try JSON API first.
- If 403/404, rotate through 4+ HTML proxies and scrape them.

## 4. Key Logic Components

### 4.1. Date Parsing (`parseDate` helper)
Converts diverse formats into standard `YYYY-MM-DD` and numeric timestamps:
- Relative: "2 hours ago", "5 days", "1 month".
- Absolute: "May 22", "2024-01-01".
- Fixed short years: `'24` -> `2024`.

### 4.2. Title Cleaning (`cleanTitle` helper)
- Double HTML entity decoding (handles `&amp;eacute;` etc.).
- Regex cleaning for technical residues.

### 4.3. Magnet Enhancement
Every magnet link is enhanced with:
- `dn`: Encoded Display Name.
- `tr`: A static list of high-tier public trackers.

## 5. Deployment & Maintenance
- **GitHub Sync:** Pushing to `main` triggers Vercel redeploy.
- **Build Command:** `npm run build` (generates `/dist`).
- **Launchers:** `launch-windows.bat` and `launch-mac.command` automate `npm install` and server start for novices.

## 6. Security
- **CORS:** Enabled on backend to allow frontend communication.
- **Anti-Bot Bypass:** Uses a `COMMON_HEADERS` object with realistic User-Agent and Sec-CH-Ua headers to reduce 403 errors in Cloud environments.
